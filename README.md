# Yiming Liao — Academic Website

Personal academic website for Yiming Liao, a master's student in Electrical and Computer Engineering at Rutgers University.

Website: https://yimingliao58.github.io/

Repository: https://github.com/yimingliao58/yimingliao58.github.io

This website uses plain HTML and CSS. No build step, package installation, or backend is required.

## Files

- `index.html`: biography, research projects, education, and contact links.
- `styles.css`: typography, colors, and responsive layouts for desktop and mobile.
- `assets/yiming-liao.jpg`: profile photo.
- `.nojekyll`: serves the files directly through GitHub Pages.

## Publish with GitHub Pages

1. Add these files to the root of the chosen GitHub repository, preserving the `assets` folder and `.nojekyll` file.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the website, usually **main**, and the **/ (root)** folder, then save.
5. Wait for the Pages deployment to finish. GitHub shows the website URL in the same settings page.

A repository named `<username>.github.io` publishes at `https://<username>.github.io/`. Other repository names publish at `https://<username>.github.io/<repository>/`.

After setup, commits to the selected branch automatically update the published website.

## Edit and preview

Edit `index.html` to update the content and `styles.css` to adjust its appearance. Keep the relative stylesheet and photo paths so the site works at either type of GitHub Pages URL.

Open `index.html` in a browser for a local preview.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
